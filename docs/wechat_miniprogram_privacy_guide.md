# 港研通微信小程序隐私保护指引填写稿

更新时间：2026-07-18

建议平台显示生效日期：2026-07-18

适用 AppID：`wxb48f01b7bf2f919b`

本文件用于微信公众平台“账号设置 → 服务内容声明 → 用户隐私保护指引”的人工填写。填写内容必须与当前小程序代码和实际服务一致；以后启用手机号、微信支付、定位、摄像头或麦克风时，需要重新更新并提交隐私指引。

## 当前代码实际处理的信息

- 微信登录标识：后端用微信登录临时 `code` 换取 `OpenID`，用于识别同一微信用户、创建账号和保持会话。
- 邮箱账号信息：用户主动填写的邮箱、邮箱验证码和登录凭证，用于备用登录、注册、找回密码及微信账号绑定。
- 个人资料：用户主动填写或选择的昵称、头像、性别和考试目标。
- 学习数据：答题记录、正确率、错题、收藏、练习历史、能力统计、学习报告和训练记录。
- 反馈信息：用户主动提交的反馈内容及可选联系方式。
- 头像和题目素材：用户主动选择的头像图片；管理员主动选择的题目图片或题库文件。
- AI 助教数据：使用 AI 助教时，当前题目、用户提问、是否已提交答案、所选答案以及生成训练所需的题目或薄弱点上下文会发送到 DeepSeek API，用于生成解题回复或专项练习；不主动发送邮箱、微信 `OpenID`、昵称或头像。
- 安全运行信息：服务器为保障账号和接口安全可能记录访问时间、请求路径、IP 地址和错误日志。

当前版本不获取手机号，不调用微信支付，不获取位置、通讯录、摄像头或麦克风。

## 信息对外提供与受托处理

平台指引不得填写绝对的“不会向任何第三方提供信息”，因为当前服务实际使用微信登录、Supabase、腾讯云、DeepSeek API 和邮件发送服务。建议在对应栏目填写：

```text
港研通不会出售用户个人信息，也不会将信息用于第三方广告追踪。为实现微信登录、账号认证、数据存储、后端运行、邮箱验证码及用户主动使用的 AI 学习辅助功能，我们可能委托必要的技术服务提供方在限定目的和必要范围内处理信息，包括微信小程序平台、Supabase、腾讯云、DeepSeek API 和邮件发送服务。使用 DeepSeek API 时，仅发送当前题目、用户提问、答题状态、所选答案及生成训练所需的必要上下文，不主动发送邮箱、OpenID、昵称或头像。管理员主动使用题目图片识别功能时，所选图片可能由腾讯云 OCR 服务处理。我们要求相关服务提供方采取合理的安全保护措施；如处理范围发生实质变化，将更新指引并依法履行告知或取得同意的义务。
```

如微信后台要求逐项填写第三方名称、处理信息和用途，按下表填写，并以实际启用配置为准：

| 服务 | 必要处理的信息 | 用途 |
| --- | --- | --- |
| 微信小程序平台 | 微信临时登录凭证、OpenID | 微信登录、识别同一微信用户 |
| Supabase | 账号资料、学习数据、用户主动上传的头像 | 账号认证、数据库和对象存储 |
| 腾讯云 | 接口请求、必要安全日志；管理员主动选择的题目图片 | 后端运行、安全保障和题目图片 OCR |
| DeepSeek API | 当前题目、用户提问、答题状态、所选答案、必要训练上下文 | 生成 AI 回复或专项练习 |
| 邮件发送服务 | 邮箱地址、验证码邮件 | 注册、绑定邮箱和找回密码验证 |

不得填写“向第三方出售信息”“用于广告推荐”或“公开披露用户信息”，当前业务不存在这些行为。

## 当前不要勾选

- 收集你的手机号
- 收集你的位置信息或选择的位置信息
- 收集你的地址、发票信息或车牌号
- 访问你的麦克风、摄像头或蓝牙
- 使用你的相册写入权限
- 微信运动步数

小程序端已取消通过剪贴板复制链接和邮箱，因此不应勾选“读取你的剪切板”。如微信代码检测仍提示该项，应先检查最新构建产物，不要为了通过检测而填写虚假用途。

## 提审前人工核对

1. 在微信公众平台更新并保存“现网版本用户隐私保护指引”。
2. 打开手机预览，确认“更新日期”和“生效日期”均不再显示 `1970年1月1日`；本次建议显示 `2026年7月18日`。
3. 上传新代码后，在提交审核页面再次检查“提审版本隐私保护指引”。
4. 确认自动检测项只有当前实际使用的照片、文件等能力。
5. 确认第三方处理说明没有使用“绝不向任何第三方提供”的绝对表述，并已如实说明当前必要技术服务。
6. 在体验版首次点击邮箱登录、注册、找回密码或微信登录，确认会出现微信隐私授权流程。
7. 拒绝授权时不得发送登录或注册请求；再次操作后应允许重新授权。
8. 在登录页、关于我们和学习功能说明页点击《用户隐私保护指引》，确认可打开微信平台指引。
9. 个人资料选择头像前应再次经过微信隐私检查。
