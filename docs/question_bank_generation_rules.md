# 题库生成规则

本文档保存港研通题库生成的硬规则。生成、校验、修复和导入题库时，先遵守本文件；若用户在当前会话给出更具体要求，以用户最新明确指令为准，但不得违反数据库格式、dry-run、环境变量安全和正式导入确认等硬性规则。

## 通用硬规则

- 最终 JSON 顶层必须是 `{ "questions": [...] }`。
- 每题必须是单项选择题，`question_type` 固定为 `single_choice`。
- 每题只能有 1 个最佳答案，`answer` 只能是 `A`、`B`、`C`、`D`。
- 每题必须展开 `option_a`、`option_b`、`option_c`、`option_d`。
- `difficulty` 只能是整数 `1`、`2`、`3`、`4`、`5`。
- `source_year` 使用 `2026`。
- 非阅读材料题 `passage_id` 固定为 `null`。
- 不得生成阅读理解、完形填空、翻译、作文、材料分析、证明题或开放题，除非对应模块另有明确任务。
- 不得照搬资料原题；只能参考题型、考点、难度和干扰项设计。
- 不得出现答案不唯一、语境不足、争议性强或明显超纲的题。
- 生成后必须校验；校验不通过时自动修复后重新校验。
- 导入数据库前必须先 dry-run。
- dry-run 不通过不得正式导入。
- 正式导入必须满足 `Invalid questions: 0`、文件内重复题为 `0`，并取得用户明确同意。
- 不得上传、打印或提交真实 `.env` 内容。
- 不得使用 `git add .`。
- 不得直接导入未经确认的旧批次或被用户明确否定的批次。

推荐 dry-run：

```powershell
& "C:\Users\1111\Documents\New project\backend\.venv\Scripts\python.exe" scripts\import_questions.py --file data\<file>.json --dry-run
```

推荐正式导入：

```powershell
& "C:\Users\1111\Documents\New project\backend\.venv\Scripts\python.exe" scripts\import_questions_bulk.py --file data\<file>.json --batch-size 100
```

## 英语运用：语言知识

### 项目背景

为 `英语运用` 模块生成 `语言知识` 单项选择题，并确保生成结果符合当前数据库 `questions` 表及导入脚本格式。

### 资料来源

优先参考：

- `英语运用/kaoyan_english_vocab_5500.csv`
- `英语运用/kaoyan_english_phrases_600.csv`
- `英语运用/english_grammar_points.md`
- `英语运用/english_official_examples.md`
- `英语运用/english_recall_questions.md`

使用要求：

- 词汇题优先使用 `kaoyan_english_vocab_5500.csv` 中的词汇。
- 搭配题优先使用 `kaoyan_english_phrases_600.csv` 中的词组和固定搭配。
- 语法题优先依据 `english_grammar_points.md`。
- 命题风格参考官方样题和真题回忆。
- 不照搬资料中的原题。

### 题型要求

- 题目必须模仿港澳台考研英语运用 `语言知识` 题型。
- 每题为英文句子填空题，题干中必须包含 `____`。
- 每题提供 4 个英文选项。
- 解析必须使用中文。
- 不生成偏专四、专八或语言学专业考试的冷僻语法题。
- 不使用极冷僻词汇、古旧表达或争议性用法。

### 数据库字段

每题必须包含：

```text
exam_code      COMMON
subject        英语运用
module         语言知识
submodule      词汇 / 语法 / 语用
question_type  single_choice
stem           英文填空题干，必须包含 ____
option_a       英文选项
option_b       英文选项
option_c       英文选项
option_d       英文选项
answer         A / B / C / D
explanation    中文解析
difficulty     1-5
source_type    ai_generated / source_extracted / manual / real_exam
source_year    2026
passage_id     null
```

禁止在最终导入 JSON 使用这些非数据库字段：

```text
section
stem_en
options
explanation_zh
knowledge_area
sub_point
tags
source_style
quality_note
```

如需保留这些信息，只能放入单独审核报告，不得放入最终导入 JSON。

### 命题范围

`submodule` 只能使用：

- `词汇`：词汇辨析、近义词辨析、近形词辨析、同根词辨析、语境选词。
- `语法`：时态语态、非谓语动词、从句、虚拟语气、比较结构、主谓一致、倒装、省略、强调、代词、冠词、连词等基础语法。
- `语用`：固定搭配、介词短语、习惯表达、常见句型、语境中的自然表达。

### difficulty 规则

- `1` 入门题：非常基础的词义、常见搭配、简单句型。
- `2` 基础题：高频词汇、常见固定搭配、基础语法。
- `3` 中等题：接近港澳台考研真题主体难度，需要结合语境判断。
- `4` 较难题：近义词、近形词、同根词干扰较强，或语法结构稍复杂。
- `5` 挑战题：需要较强语境判断、搭配判断或综合语法判断，但不能冷僻、怪异或有争议。

难度应贴近港澳台考研 `英语运用 - 语言知识`，不得明显偏高考基础题，也不得偏专四、专八或语言学专业考试。

### 命题风格

- 题干简短、自然，接近真实考试。
- 英文句子符合英语表达习惯，避免中文式英语。
- 语境优先使用学习、工作、社会、教育、文化、日常交流等常见场景。
- 选项之间必须有迷惑性。
- 干扰项来自近义词、近形词、同根词、常见误搭配或结构相近表达。
- 不使用明显离谱、词性完全不相关或一眼可排除的干扰项。
- 解析只说明正确答案的关键依据，不写成长篇语法讲义。

### 质量检查

生成后必须检查：

- JSON 可解析，数量准确。
- 字段完整，固定字段值正确。
- `submodule` 只使用 `词汇`、`语法`、`语用`。
- `stem` 包含 `____`。
- 四个选项均为英文且不重复。
- 正确答案唯一。
- 解析为中文，且能说明正确项依据。
- `source_type` 为允许值。
- 不存在重复题干。
- 不存在严重同质化。
- 不混入阅读、完形、翻译、作文等非语言知识题型。

## Z002 数学基础

### 项目背景

为 `Z002`《综合能力（二）》中的 `数学基础` 模块生成单项选择题，并确保生成结果符合当前数据库 `questions` 表及导入脚本格式。

### 资料目录

数学资料目录固定为 `数学基础/`。生成题目前必须尽量读取可解析资料，不得只参考单一文件。

当前优先资料：

- `数学基础/Z002.pdf`；若存在 `z002_outline.pdf`，以该文件为准。
- `数学基础/math_official_examples.md`
- `数学基础/math_recall_questions.md`
- `数学基础/微积分(第五版)(经济应用数学基础) (赵树嫄).pdf`
- `数学基础/高等数学教材上册【第七版】.pdf`
- `数学基础/高等数学教材下册【第七版】.pdf`
- `数学基础/《基础过关660》-高数篇.pdf`
- `数学基础/27武忠祥《高数基础篇》.pdf`
- `数学基础/专升本高数2000题.pdf`
- `数学基础/专升本高等数学《2005-2023历年真题集》（高清可打印）.pdf`
- `数学基础/2025年广东省普通专升本高等数学真题试卷.pdf`
- `数学基础/27版经综800题试题册高数篇.pdf`

`math_official_examples.md` 和 `math_recall_questions.md` 用于把握题型、题干长度、选项设置和难度。教材和练习册用于核对知识点、公式和常见题型。PDF 无法直接解析时，应先转换或抽取文本。

### 允许范围

数学基础只允许生成以下三大范围内的题。

`一元函数微分学`：

- 极限
- 连续
- 导数
- 微分
- 高阶导数
- 洛必达法则
- 单调性
- 极值与最值
- 凹凸性
- 拐点
- 渐近线

`一元函数积分学`：

- 原函数
- 不定积分，最终导入数据库时映射为 `原函数`
- 定积分
- 变限定积分
- 牛顿-莱布尼兹公式
- 换元积分
- 分部积分
- 几何应用
- 定积分物理应用

`多元函数微分学`：

- 偏导数
- 全微分
- 二阶偏导
- 链导法则
- 隐函数求导
- 二元函数极值
- 二阶连续可导函数极值点的必要条件和充分条件

禁止生成：

- 线性代数
- 概率论与数理统计
- 无穷级数
- 常微分方程
- 二重积分、三重积分
- 曲线积分、曲面积分
- 空间解析几何
- 复杂物理应用题
- 证明题
- 开放式解答题
- 任何超出 `Z002` 数学基础范围的题

### 题型规则

- 每题必须是单项选择题，4 个选项。
- 题干简短直接，接近港澳台考研数学基础真题风格。
- 不生成大题、证明题、填空题。
- 不生成计算量过大的题。
- 不生成需要长篇推导才能完成的题。
- 数学表达式必须使用 LaTeX，优先用 `\(...\)` 包裹行内公式。
- 选项可以是数值、区间、表达式或判断结论。
- 干扰项来自常见错误：漏负号、漏常数、误用公式、混淆凹凸/单调区间、链式法则系数错误、积分上下限处理错误等。

### 数据库字段

每题必须包含：

```text
exam_code      Z002
subject        数学基础
module         一元函数微分学 / 一元函数积分学 / 多元函数微分学
submodule      允许范围中的最贴切考点
question_type  single_choice
stem           中文题干，数学表达式使用 LaTeX
option_a       数学表达式使用 LaTeX
option_b       数学表达式使用 LaTeX
option_c       数学表达式使用 LaTeX
option_d       数学表达式使用 LaTeX
answer         A / B / C / D
explanation    中文详细解析
difficulty     1-5
source_type    ai_generated / source_extracted / manual / real_exam
source_year    2026
passage_id     null
```

可选辅助字段可用于工作稿或审核报告，但不得依赖它们完成数据库导入：

```text
id
section
options
solution_steps
knowledge_area
sub_point
tags
source_style
quality_note
```

### difficulty 规则

- `1` 入门题：直接套公式，计算一步完成。
- `2` 基础题：常规计算，涉及 1-2 个知识点。
- `3` 中等题：接近真题主体难度，需要基本变形。
- `4` 较难题：需要技巧，如等价无穷小、换元、分部积分、链式法则组合等。
- `5` 挑战题：综合度较高，但不能超纲、怪异、繁琐或有争议。

大批量生成时，以 `difficulty=2` 和 `difficulty=3` 为主，`difficulty=5` 不宜过多。

### 解析要求

每题 `explanation` 必须详细，适合 App 用户学习，至少包含：

- 解题思路：说明本题先看什么、用什么方法。
- 关键公式：写出用到的极限、导数、积分、偏导或极值判定公式。
- 逐步推导：给出必要计算过程，不得只写“代入公式”。
- 答案理由：明确为什么对应选项。
- 易错点提醒：指出符号、系数、上下限、链式法则、定义域、凹凸方向等常见误区。

解析要清楚，不写成长篇教材式证明，不使用“根据公式可得”“显然选 A”等空泛表述。

### 质量检查

生成后必须检查：

- JSON 可解析，数量准确。
- 字段完整，固定字段值正确。
- `module` 只使用允许的三大模块。
- `submodule` 只使用允许考点。
- 四个选项不重复。
- 正确答案唯一。
- 数学表达式使用 LaTeX。
- `explanation` 包含思路、公式、推导、答案理由和易错点。
- 不存在重复题干。
- 不存在严重同质化。
- 不混入超纲内容。
- 不照抄资料原题。
