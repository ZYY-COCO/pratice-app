# 中华文化、英语运用、数学基础出题模型 V2

> 2026-09-01 更新：中华文化解析生成已升级为
> [culture_explanation_model_v3.md](culture_explanation_model_v3.md) 的结构化教学契约；英语运用和数学基础继续使用本文 V2 契约。已发布中华文化 V2 解析仍兼容读取，本次升级不代表全库已重写或发布。

本文档描述在线 AI 专项出题中三科的生成契约、质量门和复核流程。逻辑推理继续使用
`docs/logic_question_model_v2.md`，本文件不改变题库导入流程，也不代表任何题目已经入库。

## 1. 统一流水线

三科在线题统一执行：

```text
确定合法科目与考点
→ 按学科 V2 契约生成候选题
→ 本地确定性质量门
→ 隐去生成答案与解析
→ 第二次独立作答复核
→ 答案一致且无质量问题才接收
→ 失败原因回填下一轮提示词
→ 最多沿用现有 4 轮重试上限
```

模型返回“已核验”“答案唯一”等字段只是一份待审合同，不作为正确证明。中华文化和英语必须再过盲审；数学还必须先通过本地可执行复算。

## 2. 分类与考试代码

- 中华文化：在线训练可服务 Z001、Z002，题目按共享题存储为 `COMMON`。
- 英语运用：在线训练可服务 Z001、Z002，题目固定存储为 `COMMON`。
- 逻辑推理：只允许 Z001，题目存储为 `Z001`。
- 数学基础：只允许 Z002，题目存储为 `Z002`。

用户手动传入的科目、模块或考点不在 `backend/app/question_catalog.json` 时，在调用模型前直接返回 422，不再让模型自由改分类。

## 3. 中华文化 V2

### 3.1 生成要求

- 只考稳定、核心、无争议的普通文化常识。
- 先固定人物、时代、作品、制度、典籍、概念或器物的事实关系，再写题。
- 干扰项来自同朝代、同流派、同体裁或同门类知识。
- 不生成材料题、图片题、冷僻考据题和命题过程元话术。
- 解析使用中文，并采用“短块首屏、辨析展开”的结构化格式：解题思路：、选项解析：、知识点：、记忆方法：四个标签必须保留；总长度控制在 130-420 字符，A-D 四项辨析各用一行短理由。旧标签为什么、关键知识、易混辨析、记忆提醒继续兼容读取，新生成内容优先使用 V2 标签。

### 3.2 `culture_v2` 必填信息

- `question_form`
- `fact_anchor`
- `answer_basis`
- `evidence_excerpt`
- `reasoning_chain`
- `knowledge_extension`
- `memory_hook`
- `scope_level = core`
- `controversy_status = stable`
- `distractor_errors`
- `verification_status = cross_checked`
- `difficulty_features`

本地质量门会检查答案是否真正落在事实锚点或答案依据中、三个错项是否分别有具体错因，并检查解析四个区块是否完整、是否超过总长度上限，以及是否出现时代错置、材料依赖和元话术等风险。之后盲审模型只看题干与 A-D，不看生成答案和解析，独立核事实并作答。

三个教学字段分别承担不同职责：

- `reasoning_chain`：题干线索 → 相关事实 → 答案结论，必须补出中间推理，不能只写“X 对应 Y”。
- `knowledge_extension`：从当前题扩展出的独立复习事实，不得夹带“选 A/选 B”等作答结论。
- `memory_hook`：关键词、对比组、人物—作品—时代链等可复用记忆抓手；没有有价值口诀时保持简短即可。

解析质量门同时拦截“题干对象”“核心对应”“可保留”“句中空缺应填”等机械模板词、资料截断省略号和无起始内容的右引号。对存在答案冲突、双重正确项或缺失原文的存量题，V2 计划必须标记 `manual_review`，发布预览只包含已通过质量门的题目，并完整记录排除 ID。

## 4. 英语运用 V2

### 4.1 生成要求

- 只允许 `语言知识`，考点只能是 `词汇`、`语法`、`语用`。
- 题干必须是自然英文句子，并且恰好包含一个 `____`。
- A-D 都是英文，解析使用中文。
- 不生成阅读、完形、翻译、作文和偏专业语言学题。
- 错项围绕近义词、形近词、词性、搭配、时态语态、非谓语、从句或语域设置。

### 4.2 `english_v2` 必填信息

- `skill`
- `completed_sentence`
- `answer_rationale`
- `distractor_errors`
- `verification_checks`
- `verification_status = cross_checked`
- `difficulty_features`

本地质量门会把正确选项实际填回 `____`，要求结果与 `completed_sentence` 完全一致，同时检查英文题面、中文解析、唯一空格和题型边界。盲审模型会把四个选项逐个填回句子，独立判断是否只有一个自然、正确的答案。

## 5. 数学基础 V2

### 5.1 生成要求

- 只允许一元函数微分学、一元函数积分学、多元函数微分学及目录内考点。
- 禁止线性代数、概率统计、级数、微分方程、多重积分、空间解析几何、证明题和开放题。
- 公式使用 LaTeX。
- 解析必须包含解题思路、关键公式、推导过程、答案理由和易错点。

### 5.2 `math_v2` 必填信息

- `problem_family`
- `givens`
- `required`
- `solution_method`
- `source_expression`
- `verification_status = locally_verified`
- `verification_spec`
- `distractor_errors`
- `difficulty_features`

`verification_spec` 不是模型自报结论，而是后端真正执行的安全数学表达式。目前支持：

- `numeric_expression`
- `derivative_value`
- `partial_derivative_value`
- `definite_integral`
- `limit_value`
- `antiderivative_choice`
- `expression_choice`

后端只允许有限的算术运算和常见数学函数，不执行任意代码。它会计算目标值或逐项比较表达式，只有恰好一个选项通过且与声明答案一致时才接收。之后盲审模型再独立重算一次。

数值微分、数值积分和采样极限属于工程校验，不等同于形式化数学证明，因此盲审仍保留；采样不收敛、左右极限不一致或规格无法执行时直接拒收。

## 6. 重试与落库边界

- 静态质量门或独立复核拒收原因会进入下一轮生成提示词。
- 同一批和近期已生成题干继续做去重。
- 重试后仍不足目标题量时，整个训练生成失败，不把残缺批次当成功返回。
- 解析批量校准采用“快照 → 字段预览 → dry-run → 备份 → 暂存 → 发布 → 线上校验”的链路；除 explanation 和发布状态外，不修改既有题目字段。
- 任何后续批量题库导入仍必须先 dry-run，确认 `Invalid questions: 0`、文件内重复为 0；正式写入前保留可回滚备份。
